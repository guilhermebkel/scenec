Your AI draws. The compiler says what’s wrong.

scenec is a command-line tool and agent skill that turns a YAML scene into an SVG and tells an AI, in text, what it drew and what is wrong with it. It runs on the CPU with no image model, works with Claude Code, Codex and Cursor, and gives the same SVG from the same scene on any machine.

$ npx skills add guilhermebkel/scenec -g

A report an AI can read, line by line.

An image model needs eyes. scenec gives the AI text instead: what it drew, where, and what is wrong. The AI fixes the scene and runs it again until the report is clean.

Four things come back with every run.

Everything it prints is JSON, so any agent can parse it. A typo costs one more cycle, not a failure.

Warnings

Fields it did not understand, with a “did you mean”. Missing assets. Objects out of frame.

Your agent

Picks one of 10 recipes, writes the scene, reads the report and fixes it, up to 5 times. Fix the scene, not the SVG. The skill tells the agent to never edit the SVG by hand, so the result stays repeatable.

Everything runs on your machine.

No network calls, no telemetry. Nothing leaves your computer, and nothing is downloaded at run time.

Files stay in the scene folder

The file reader refuses .. and absolute paths.

Custom SVG is allowlisted

Scripts, on* handlers, external links, <style> and entities are removed or rejected.

No model, no GPU

Plain CPU code: geometry, drawing and a rasterizer.

Hard limits

At most 200 objects and a 4096 px frame per scene.

Found a way around any of this? See SECURITY.md.

Questions

Does it need an image model or a GPU?

No. It is plain CPU code: geometry, drawing and a rasterizer. Nothing is downloaded at run time.

Can I use it without an agent?

Yes. The CLI has render, check, catalog and schema. check exits with 1 when there is a warning or critique, and with 2 when the scene is invalid.

Can I add my own drawings?

Yes. Under assets: a scene can bring an SVG, inline or as a file next to the scene, or an image. Custom SVG goes through the sanitizer.

What if the AI mistypes a field?

Unknown fields are not errors. The compiler warns and suggests the closest name, so a typo costs one more cycle.

Why can’t the agent edit the SVG?

Every correction goes back through the scene, so the same scene always gives the same SVG on any machine.

What do I need to run it?

Node.js 20 or newer, and any AI that can run a command, such as Claude Code, Codex or Cursor.
