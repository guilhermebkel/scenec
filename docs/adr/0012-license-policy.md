# 0012. Dependency license policy

Status: accepted.

Runtime dependencies may use MIT, ISC, Apache-2.0, BSD, 0BSD, PSF-2.0 or MPL-2.0. `@resvg/resvg-js` is MPL-2.0: using it unmodified as a dependency is allowed; do not copy its source into this repository. The Poppins font is OFL-1.1 and ships with its license. `pnpm check:licenses` enforces the list.
